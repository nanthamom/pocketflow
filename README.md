# PocketFlow 

PocketFlow Is A Mobile Expense Tracking App built With React Native And Expo While Learning Mobile Development from Scratch.

## Features (Current)

- Add expenses  
- Dynamic expense list  
- Automatic total spending calculation  
- iOS Simulator support  
- React Native + Expo setup  

Example:

Tesco — £10  
Waitrose — £12.99  
Coffee — £4.50  

Total: £27.49

## Tech Stack

- React Native
- Expo
- TypeScript
- Xcode Simulator (iOS)
- useState
- Arrays (`map`, `reduce`)

## What I Learned

- Setting up Expo and Xcode
- Running iOS simulators
- React state (`useState`)
- Dynamic rendering with `.map()`
- Calculating totals with `.reduce()`
- Debugging React Native and simulator errors
